## On the Line's commitments

- The first sentence identifies On the Line as an automated assistant and names the directory.
- Calls ask only about public listing fields: service status, hours, phone, location, eligibility,
  fees, and application process.
- Every proposed change is read back. A routine change publishes only after explicit confirmation.
- Removal, closure, suspension, reduced availability, and eligibility changes require a curator.
- A stop request ends the call immediately and permanently suppresses the organization.
- Calls use only the number, dates, weekdays, local hours, and call count authorized above.
- Audio is streamed for the conversation and is not retained. Redacted structured evidence is
  retained with the audit event.
- No help-seeker identity or client record is requested.
